## Key decisions and rationale

- Catalog reads require an active signed-in member or librarian; browser Firestore access remains denied.
- Book substring fields are title, author, publisher, and category. Copy substring search uses shelf location. ISBN, copy ID, publication year, and status are exact filters. Multiple filters combine with AND.
- Preserve the existing `{ isbn, items }` copy-list response. Use bounded cursor pagination for collection search.
- Keep Firestore as source of truth and initially scan filtered candidates in server code; measure before adopting a search index/service.
- Establish editable TypeScript source and build before implementing the catalog API. Remove legacy `q` rather than preserve it as an alias.
- Seed records use stable document IDs and are emulator-only. The script does not clear unrelated or previously seeded data.
