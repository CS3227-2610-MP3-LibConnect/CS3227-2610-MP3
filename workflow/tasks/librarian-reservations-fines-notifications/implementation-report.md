## Implemented behavior

- Added strict, bounded reservation/fine/message/list schemas, signed cursor
  payloads, safe DTOs, idempotency-key validation, and fixed server-owned
  overdue policy configuration.
- Added active-librarian routes for bounded reservation/fine queues and detail
  reads, outstanding-fine waiver, and plain-text member messages.
- Added transactional `FINE_UPDATED` waiver notifications, linked lost-book
  `FINE_ISSUED` notifications, deterministic overdue fines/alerts, and
  retry-safe assigned-reservation expiry.
- Added hashed seven-day librarian-message idempotency records. Identical
  retries replay the notification; mismatched payload reuse returns `409`;
  raw keys are not stored or logged.
- Added the member-slice integration contract and tests without duplicating
  Jun Hong's member routes or UI.
- Added the protected librarian reservations/fines UI with filters, bounded
  queues, explicit waiver/message confirmation, pending-submit protection,
  accessible status/error/empty/loading states, and refresh-after-success.
- Added Firestore index entries and a reproducible emulator test script.
- Narrowed librarian notification response DTOs so internal recipient user IDs
  are not returned to the librarian client.
