## Key decisions and rationale

- On a successful member borrow, atomically set the copy to `ON_LOAN` and clear `shelfLocation` to `null`; failed attempts retain the existing location. This reflects that a borrowed copy is no longer on a shelf.
- Allow null shelf locations in the shared copy schema and member catalog copy type; show “Not on shelf” in the member book-detail copy list.
- Keep librarian loan creation behavior unchanged. Staging remains read-only and does not reserve copies.
