# Jiali's Responsibilities

- Own the librarian and librarian-manager feature area.
- Implement the librarian catalog and inventory workflows, including books, book
  copies, copy status, and librarian-facing dashboards.
- Implement librarian circulation workflows, including creating loans, reviewing
  returned or lost reports, choosing return dispositions, and handling reservations.
- Implement librarian-side fines, notifications, member-account support, and
  manager-only librarian-account administration.
- Own the server-side authorization and transaction rules for librarian and
  manager actions, including role checks and state-transition validation.
- Lead the librarian/manager AI assistant for summarising pending reports and
  preparing notification drafts. AI must not perform state-changing actions
  without human approval.
- Add librarian, manager, cross-role, and state-transition tests, and contribute
  to the integration documentation and final acceptance review.
